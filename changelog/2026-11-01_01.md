# The Memory-Layers Study's 18 Profiles Become a Bundle Any Agent Can Read

## Why Care?

`memory-layers-for-agents/context-v/` holds one deep profile per pinned memory layer, from Mem0 and Graphiti to Beads and StateBench. Until today an agent had to open each file to learn what it was. Now the folder is an Open Knowledge Format (OKF) v0.2 bundle, so any OKF reader can list the profiles and what each one argues without opening a thing.

## What's New?

- **All 18 profiles declare `type: Profiles`**, the Train-Case name of the folder they live in.
- **`context-v/index.md`** marks the bundle with `okf_version: "0.2"` and lists its one folder.
- **`profiles/index.md`** has one line per profile, using its lede.
- **This `changelog/`** is new; this is its first entry.

## Under the Hood

- Part of the tree-wide OKF sweep; see the Context Vigilance Kit's plan, [[Retrofit-Every-Repo-to-OKF-Then-the-Kit-Frontmatter]].
- Every edit was made by hand, one file at a time. The doc diff is 18 added `type:` lines and nothing removed. No dates moved: this is a compliance change, not a content change.
- The pinned upstream repos beside `context-v/` are submodules and were not touched.
